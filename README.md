# 英语短片 · 云端自动生成（GitHub Actions）

这台机器不用你管，电脑关机断网也不影响。

## 它在做什么
1. 把 28 张卡通首帧图传到图床，拿到 72 小时有效的公网链接
2. 调 Agnes 生成视频（3 路并发，短镜头优先，队列满就等下一轮）
3. 生成的 mp4 放进 `output/`，并自动提交回本仓库

## 怎么用
- **自动跑**：每 2 小时一次，不用管
- **手动跑**：仓库页面 → Actions → 左边选 "Agnes 视频生成" → 右边点 "Run workflow"
- **拿结果**：
  - 方法一：直接看仓库里的 `output/` 文件夹（已自动提交）
  - 方法二：Actions 页 → 对应的运行记录 → 底部 Artifacts → 下载 zip

## 目录说明
- `frames/` 28 张卡通首帧图（首帧模式用，锁定画面风格）
- `scripts/` 生成脚本
- `scripts/manifest.json` 是镜头清单（首帧链接、时长、运动描述）
- `output/` 生成出来的视频
